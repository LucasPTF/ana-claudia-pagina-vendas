# Aula Dedo Podre Nunca Mais

Página de vendas desenvolvida para Ana Cláudia, com comunicação voltada a mulheres 40+ que desejam compreender padrões afetivos recorrentes e dar o primeiro passo para uma vida amorosa mais consciente.

## Tecnologias

- Next.js
- React
- TypeScript
- CSS responsivo

## Rotas disponíveis

- `/a1`
- `/a2`
- `/a3`
- `/obrigado`

As três rotas de vendas usam a mesma estrutura, identidade visual, conteúdo e componentes. Somente a comunicação inicial é alterada para permitir comparação.

## Execução local

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000/a1` no navegador.

## Validação

```bash
pnpm validate
pnpm lint
```

## Build de produção

```bash
pnpm build
pnpm start
```

## Informações pendentes

- Link oficial do checkout
- Data e horário da aula
- Plataforma de transmissão e acesso
- Contato de suporte
- Domínio personalizado

O link do grupo oficial de WhatsApp fornecido nos materiais está configurado na página `/obrigado`.
